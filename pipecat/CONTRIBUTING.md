# Contributing

Thank you for your interest in contributing to this project!

Contributions are welcome. If you'd like to improve the project, please follow these simple steps:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make and test your changes.
4. Submit a Pull Request (PR).

## Guidelines

- Keep changes focused and relevant.
- Follow the existing project structure and coding style.
- Update the documentation if needed.
- For major changes, please open an issue or start a discussion first.

All Pull Requests will be reviewed before being merged.

Thank you for contributing!
